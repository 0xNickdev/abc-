# 📘 ABC — инструкция для чайников

Это пошаговая инструкция. Просто делай сверху вниз. Копируй команды как есть.

> 💡 Главное, что нужно понять:
> **Сейчас всё работает на ненастоящих деньгах (режим SHADOW).**
> Ты НИЧЕГО не теряешь. Можно тыкать что угодно. Реальные деньги выключены отдельным замком.

---

## ШАГ 1. Открыть терминал

На Mac: нажми `Cmd + Пробел`, напиши **Terminal**, нажми Enter.
Откроется чёрное окно — это терминал. Сюда вставляем команды.

---

## ШАГ 2. Запустить программу

Скопируй эти **3 строки целиком**, вставь в терминал, нажми Enter:

```bash
cd /Users/johnbuz/Downloads/bot123/aitrader
. .venv/bin/activate
python app.py
```

Если увидишь что-то вроде `Uvicorn running on http://127.0.0.1:8000` — **значит работает.** 🎉

⚠️ Это окно терминала теперь НЕ закрывай — пока оно открыто, программа работает.
Чтобы выключить программу позже — вернёшься сюда и нажмёшь `Ctrl + C`.

---

## ШАГ 3. Открыть приложение в браузере

Открой Chrome/Safari и зайди на адрес:

```
http://localhost:8000
```

Это и есть твоё приложение — терминал ABC. Тут кнопки, списки токенов и т.д.

---

## ШАГ 4. Что ты видишь

- **Список токенов** — это результат скрининга (что прошло фильтры).
- Зелёные/прошедшие — кандидаты на покупку.
- Можешь нажимать «купить» — это **бумажная** покупка (деньги не настоящие).
- Внизу — твои «позиции» (что ты «купил») и их прибыль/убыток.

Тыкай спокойно. Всё понарошку.

---

## ШАГ 5. Включить бота (он торгует сам)

Бот сам ищет хорошие монеты и сам «покупает/продаёт» (бумажно).

Открой **второй** терминал (`Cmd + N` в Терминале) и вставь:

```bash
cd /Users/johnbuz/Downloads/bot123/aitrader
. .venv/bin/activate
curl -sX POST localhost:8000/api/strategy/apply
curl -sX POST localhost:8000/api/bot/start -H 'content-type: application/json' -d '{"chain":"sol"}'
```

Бот запущен. Теперь он раз в 20 секунд проверяет рынок и торгует сам.

**Посмотреть, что бот наделал** (подожди минуту, потом вставь):
```bash
curl -s localhost:8000/api/bot
```
Увидишь цифры: `buys` (купил), `sells` (продал), `errors` (ошибки).

**Остановить бота:**
```bash
curl -sX POST localhost:8000/api/bot/stop
```

---

## ШАГ 6. Посмотреть «оценки» (как идёт торговля)

```bash
curl -s localhost:8000/api/backtest
```

Тут — настоящий счёт по закрытым сделкам:
- `win_rate` — процент прибыльных сделок (0.6 = 60%);
- `trades` — сколько сделок было;
- если сделок ещё нет — напишет `trades: 0` (это нормально, просто подожди/погоняй бота).

👉 **Правило:** держи бота на бумаге (SHADOW) долго. Когда `win_rate` стабильно хороший — тогда думай про реальные деньги.

---

## ШАГ 7. Выключить всё

1. В терминале с ботом: `curl -sX POST localhost:8000/api/bot/stop`
2. В первом терминале (где `python app.py`): нажми `Ctrl + C`.

Всё выключено.

# ❓ Частые вопросы

**«Я ничего не сломаю?»**
Нет. Деньги ненастоящие (SHADOW). Реальная торговля выключена отдельно.

**«Где настоящие деньги включаются?»**
Только если специально снять замок: запустить через `ENABLE_LIVE_TRADING=1 python app.py` И переключить режим на LIVE И заложить ключ кошелька. Пока ты этого не сделал — всё бумажное.

**«Бот ничего не купил, почему?»**
Это нормально — бот покупает ТОЛЬКО когда монета прошла все строгие условия. Если рынок «никакой» — он ждёт. Дисциплина важнее активности.

**«Сервер не запустился / ошибка»**
Убедись, что ты ввёл все 3 строки из ШАГА 2 по порядку. Вторая строка (`. .venv/bin/activate`) обязательна.

**«Как проверить что код рабочий?»**
```bash
cd /Users/johnbuz/Downloads/bot123/aitrader
. .venv/bin/activate
python -m pytest -q
```
Должно написать `60 passed`.
